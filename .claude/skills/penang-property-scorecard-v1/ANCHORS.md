# 檳城評分卡錨表 — 已鎖定規格 v1.0（2026-08-06）

本檔是 `penang-property-scorecard-v1` 的錨表單一真實來源，由四份獨立研究彙整後鎖定。
**產卡時直接引用本檔，不得重新研究市場層級事實**（區域行情、開發商評級、法規門檻）——那是 KL 那批卡每張燒 27 萬 token 的主因。

**尺規宣告**：檳城採**自身內部尺規**，檳城最高地段錨在 8.0。**檳城分數與 KL／曼谷分數不可直接比大小**，跨市場比較走 macro／markets-summary 那層。

- 已憲報 RSNPP 2030 明列填海是「解決土地有限的有效替代方案」
- 首長 2026-06-11：「土地稀缺不是障礙」，正收購 809–1,214 英畝
- 首長 2026-05-14：「填海地出售是州政府主要收入來源，若枯竭將難以替代」→ **造地動機部分是財政而非空間**
- MBPP 土地利用稽核（2024-01）：島上僅 **6.19%** 為未開發地（森林 45.66%、農業 14.04%、建成 31.13%）

**不可當法規鎖計分**：「50% 最低森林覆蓋」是**聯邦**政策非檳城州；檳城升旗山生物圈保留區**無獨立法律效力**（過渡區明文支持開發）。

**填海前線（土地層 ✗ 觸發清單）**：Andaman Ph2 507 英畝（2028）· E&O 未開發地 756.9 英畝（30 年）· Silicon Island 930.77 ha（實速僅指引之半）· **Islands B&C 2,200 英畝「擱置非放棄」** · Penang Port NBCT 322.83 ha（狀態不明）。已終止：Bagan Ajam 582 ha（2025-09-22）。

## §3 d3 持有現金流（12%，本／外分開）

**檳城島上精華區毛收益普遍 2.7–3.8%，若照 KL 階梯全部擠在 4.0 → d3 失去鑑別力。**
**解法：≥4.0% 各級距與 KL 完全相同（保住跨市場可比），只在 4.0% 以下增設解析度。**

| Gross yield | 本國人 d3 | |
|:---|:---:|:---|
| ≥5.5% | 7.0 | 同 KL |
| 5.0–5.5% | 6.0 | 同 KL |
| 4.5–5.0% | 5.0–5.5 | 同 KL |
| 4.0–4.5% | 4.5 | 同 KL |
| **3.5–4.0%** | **3.8** | 新增 |
| **3.0–3.5%** | **3.2** | 新增 |
| **<3.0%** | **2.5** | 新增 |

本國人 clamp **[2.5, 8.0]**；外國人 ＝ 本國人 −2.0，clamp **[1.5, 8.0]**。
**clamp 碰撞例外**：本國人 ≤3.5 時外籍觸底，本外差距壓縮至 <1.5 — **這是允許的例外，非計算錯誤**，須在卡上標註。

**調整項**：
- **島上住宅地契：短租收入一律不計、不得給 Airbnb 加分（R4）**
- 島上商業地契 SA/SOHO/SoFo/SoVo：短租合法但受 **180 天/年、每次 ≤3 天**限制 → 最多 **+0.2**（非 KL 的 +0.5），須有 JMB/MC 登記佐證
- 本島外：住宅地契亦可短租，須 ¾ 特別決議 → 最多 +0.3
- Bayan Lepas／Bayan Baru／Queensbay：E&E 企業租約（1–2 年、公司付租）+0.2
- Gelugor／Minden：USM 分租房拉高毛 yield 但**口徑是分租非整戶** → **不加分**，卡上須註明口徑
- Batu Ferringhi：長租池淡薄＋不得短租 → **−0.3**
- 商業地契 −0.3
- 管理費門檻：**無檳城可驗證數據**，暫留 KL 的 RM0.6 psf 並標「待校準」

**收益率資料品質（每張卡必須聲明）**：NAPIC／Penang Institute／The Edge／Knight Frank **均不發布檳城租金或收益率**。所有 yield 皆為入口網站掛牌價推算，一律標 **估算**。
**來源黑名單**：propcashflow.my、bambooroutes.com、clickbina.com、alpianaliproperty.com、kitalent.com（內容農場，IQI 引用的 Batu Kawan「5–7%」即源於此，實算為 3.4–4.6%）

### 6.10 R7：退場價低於外籍門檻的三段式階梯（2026-08-07 新增）

**R3 的實質不是「島上 landed」這個產品規則，而是「一般外籍買家法定不可購買」這個價格事實。**R3 只是該事實在島上 landed（門檻 RM300 萬）的一個特例。一般化如下——**先照 §6.7 逐項算出 d6_外 原始值，再套 cap**：

| 退場價 vs 門檻（門檻見 §6.1） | 實際可購買人群 | d6_外 |
|:---|:---|:---:|
| ≥ 一般外籍門檻（島 strata RM100 萬／島 landed RM300 萬／本島外 strata RM50 萬／本島外 landed RM100 萬） | 全部外籍 | 照常規公式，無 cap |
| < 一般門檻但 **≥ MM2H RM50 萬** | **MM2H ＋ PR** | **cap 4.0** |
| < MM2H 但 **≥ PR RM25 萬** | **僅 PR** | **cap 3.0** |
| < PR RM25 萬 | 無 | **cap 1.5**（理論值，檳城實務極罕見） |

**判定價用哪個數字（2026-08-07 補；D'Piazza 卡因此回檢）**：**一律用同建案 Brickz 成交中位**，不用代表戶開價或掛牌價——R7 測的是「退場時買家能不能合法買」，退場價的最佳估計是真實成交，這與 §7 錨點原則「用真實成交，不用別人的開價」一致。無同建案成交時才退而用同地段同類成交，並標明。**成交分布跨越門檻時**（例：D'Piazza 中位 RM53 萬 > MM2H RM50 萬，但下四分位 RM46.5 萬 < 門檻）：**取中位所在段**，同時在卡上揭露資格是**逐戶而非全棟一致**，5B 該列標 **△** 並註明條件。差別實際很大——用開價 RM49.5 萬會落 cap 3.0，用成交中位 RM53 萬則是 cap 4.0，d6_外 差 1.0 分。

**配套要求**：①外籍依賴度記 **≈0**（不得寫「低」或具體百分比）；②**5B 接手人群金字塔第 5 列「外籍自住（MM2H）」須依 MM2H 門檻獨立判定**——退場價 ≥RM50 萬時該列是 **✓ 而非 ✗**（2026-08-07 Scots Pavilion 與 Sunway Wellesley 兩張卡初稿皆誤標，因為把「低於 RM100 萬」當成單一事實，看不到 MM2H 與 PR 各自的門檻把買家池切成三段）；③**§6.7 #5 MM2H 合規 +0.3 在中間段仍應給**（人群確實存在，只是池子小）；④若退場價落在門檻附近，卡上須寫出敏感度（例如掛牌區間上緣跨過門檻則 cap 不適用）。

**已適用案例**：Botanica.CT（島上 landed，RM300 萬門檻搆不到）4.0｜Scots Pavilion（RM78 萬 < 島 strata RM100 萬，≥MM2H）4.0｜Sunway Wellesley（RM72 萬 < 本島外 landed RM100 萬，≥MM2H）4.0｜Azuria（RM30 萬 < MM2H RM50 萬）3.0。

**為何是「clamp 後的本國人分」而非 baseline**：所有本國人調整（quantum／換手／掛牌／深度／戶型／融資）描述的是**資產本身的流動性**，外籍賣方同樣面對——而且更嚴峻，因為其買家池是本地池的嚴格子集。用地契 baseline 起算等於把流動性資訊整個丟掉，方向剛好相反，且會產生「重罰後的本國人分低於未罰的外籍分」的荒謬結果。

**d3 套用同一修正**，並記載 clamp 碰撞例外（見 §3）。

## §9 已知資料缺口（不得粉飾，卡上須誠實標示）

1. NAPIC district × 型態 × 價格帶交易表 — 登入牆，需 `napic.jpph.gov.my/en/data-request` 申請
2. **檳城 days-on-market／掛牌-成交折讓 — 不存在任何公開數據**（無 MLS）。5C 該格應render「無公開數據」，**不得引用 bambooroutes 的「75–95 天」**
3. **任何機構來源的檳城租金／收益率 — 不存在**。每張卡的 yield 皆為入口網站推算，一律標估算
4. 檳城外派人士就業准證數 — 州級未公布，E&E 外籍租客池無法量化
5. 檳城管理費常規 — 無驗證數據，暫用 KL RM0.6 psf 標「待校準」
6. **掛牌重複係數 — 未測量，是流動性分析最大誤差來源**。馬國無 MLS，一位屋主常委任 5–15 位代理且入口網站不去重。**掛牌率僅供專案間相對排序，絕不可寫成「本棟 X% 在售」**。入口網站總數互相矛盾（PropertyGuru 11,707 vs iProperty 7,966，差 47%）→ **擇一並在所有檳城卡固定使用，不得平均**。
   **2026-08-07 裁定**：本條與 §6.6 原本的掛牌率四級距計分互相矛盾——2026-08-06 首批三張新卡（Muze／Light Collection II／Vertu Resort）由三個獨立 agent 產出，**三張全部依 §6.6 計分**，證明矛盾會系統性複現而非偶發。已刪除 §6.6 的級距，**掛牌率一律為揭露項不計分**，本條為唯一權威。已上線八張卡全部依此口徑（前五張本就未計分）。
7. MM2H 州級優惠與聯邦級距互動 — PTG 文件為一手且明確，但 visitpenang.com 相反，建議律師確認
8. 填海地地契（STP／Queensbay／The Light）freehold vs leasehold — **須逐案查 SPA，不得由「填海」推定**
