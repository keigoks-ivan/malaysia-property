# 前瞻預測登記簿（Forward Ledger）

依 `property-forecast-v1.md` 第 6 步運作。**條目一經凍結不得修改**；修正認知請開新條目並互相引用，舊條目照原文評分。所有條目為市場層級預測，不含任何個人持有資訊。

**評分規則（v1.0 凍結）**：
- 排序型預測：以實際成交口徑（實價登錄／Brickz 級數據）算實現報酬排序，Spearman ρ ≥ 0.6 為通過
- 量級型預測：實際值落在凍結扇形的「基本情境區間」內為通過；落在 bear–bull 全域內為部分通過
- 絆線審計：每次複評逐條記錄「已觸發／未觸發／已失效」，並記錄觸發後是否照凍結的 action 執行判斷更新
- 複評節奏：每年 7 月一次；條目各自另有指定評分日
