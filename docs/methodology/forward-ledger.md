# 前瞻預測登記簿（Forward Ledger）

依 `property-forecast-v1.md` 第 6 步運作。**條目一經凍結不得修改**；修正認知請開新條目並互相引用，舊條目照原文評分。所有條目為市場層級預測，不含任何個人持有資訊。

**評分規則（v1.0 凍結）**：
- 排序型預測：以實際成交口徑（實價登錄／Brickz 級數據）算實現報酬排序，Spearman ρ ≥ 0.6 為通過
- 量級型預測：實際值落在凍結扇形的「基本情境區間」內為通過；落在 bear–bull 全域內為部分通過
- 絆線審計：每次複評逐條記錄「已觸發／未觸發／已失效」，並記錄觸發後是否照凍結的 action 執行判斷更新
- 複評節奏：每年 7 月一次；條目各自另有指定評分日

## 條目 006：條目 004 的儀器限制記載——F1 目前不可評分（不修改 004）

- **凍結日**：2026-08-02
- **性質**：**本條不是新預測，是對條目 004 的可評分性記載。** 依本簿紀律「條目一經凍結不得修改」，004 的命題、絆線、評分日全部維持原文；此處僅登記「用現有儀器評不了」這個事實，以免 2031 評分時把儀器問題誤讀為命題被推翻。
- **發現**：`data/my-rent-index.json`（DOSM CPI 041，2010-01～2026-06，198 期）取得後確認——該指數量的是**續約中的租約存量**，197 次月變動只動 68 次、其中 66 次落在季度第二個月，實為季頻；且隨換約才逐批反映市場租金，**結構上天生落後於成交價指數 MHPI**。用它當 004 的租金腿，結果**無法分辨「Λ 機制不成立」與「儀器本來就慢」**。
- **佐證**：186 個年增觀察值從未轉負（最低 +0.394% @ 2021-02）；2022Q2–2023Q2 的 OPR +125bp 窗口租金反而加速（季環比 0.339%→0.639%），MHPI 同期一路上行——**兩條腿都無轉折，004 的 in-sample 首跑無法執行**（是空窗口，不是被污染）。004 絆線③「CPI 租金分項年增轉負」在 16 年紀錄裡從未觸發，近乎不可達。
- **處置**：004 維持凍結、維持有效。**評分日到期時若仍只有 041 可用，記為「儀器不足、無法評分」，不得記為推翻。**
- **復活條件**：取得 KL 或高層公寓分項的**成交**租金序列（掛牌價不算，違反「asking 永不當錨」）。候選價格腿：NAPIC IHPK 服務式公寓價格指數（本輪撿到線索、未取）。
- **交叉引用**：條目 004；`four-quadrant-v1.md` §7.9
