### 四象限各格能不能填滿

### 最強的一塊
**NW 的信貸序列**（BCB SGS）。這正是 `four-quadrant-v1.md` §8 記載「五因子框架六測試裡唯一站得住的鏈環」（T6 信貸領先房價）所需要的資料，巴西不只拿得到，取數體驗還比馬來西亞好——BCB SGS 是一個乾淨的公開 REST API，不需要像 NAPIC 那樣考古 October CMS 的 AJAX filter、猜檔名、拼三代不規則 URL。7 條核心序列全部實測成功並存了樣本。

### 最弱的一塊
**SE 的存量供給**。馬來西亞 NAPIC 的 Stock Report 給了 74 季（2007Q4–2026Q1）、17 個地區、完工量與存量雙欄全無缺口的官方序列——這是本站少數幾個「強項」之一。巴西完全沒有對應的東西：住宅存量與空置只能從十年一次的普查拿到單點數字，兩次普查之間（2010→2022，下一次約 2032）沒有任何官方序列可以插補。完工量／新供給勉強有 Abrainc-Fipe 這個開發商協會的月度指標可用，但它是會員開發商的統計、非普查或建照登記，涵蓋率不明；CBIC 與聖保羅市府建照資料兩條路都被防爬蟲機制擋死，連測都測不到。

**SBPE vs FGTS 的區分（任務明確要求釐清）**：BCB SGS 的家庭房貸序列是按**利率體制**（受管制 SFH vs 市場利率 SFI）切分，**不是**按資金來源（SBPE vs FGTS）切分。SFH 本身混合了 SBPE 與 FGTS 兩種資金、統一適用價格上限。SGS 上沒有找到 FGTS 專屬的個人房貸序列（🔴）。**唯一能把 SBPE 單獨切出來的是 Abecip 的月報 PDF**（上表已驗證，2026-06 SBPE 放貸 R$17.21 bi）——這代表若要做「市場價房產、非補貼住房」口徑的信貸序列，正確作法是**用 Abecip 的 SBPE 月報數字，不要直接拿 BCB SGS 的房貸總計**，因為後者含 FGTS 補貼房。

**BCB SGS API**（信貸、Selic、IPCA、INCC 皆走此路徑）：
```
GET https://api.bcb.gov.br/dados/serie/bcdata.sgs.{code}/dados?formato=json
```

- 日期格式為 `DD/MM/YYYY`（巴西式），回傳 JSON 陣列 `[{data, valor}]`
- **坑**：回傳值本身不帶單位／標題說明，需靠數量級與交叉比對推斷單位（餘額類＝R$百萬、利率類＝百分比），正式引用前應對照 SGS 網頁版 metadata 確認

## 已知限制與缺口

1. **S_total 沒有序列，只有單點。** 巴西住宅存量與空置的唯一來源是十年一次的 IBGE 普查（2010、2022，下一次約 2032／2033）。**兩次普查之間完全沒有官方序列可以插補**——這跟馬來西亞 NAPIC 74 季無缺口的 Stock Report 是本質上的差距，不是取數技巧能解決的，是**巴西的統計制度本身就沒有季度／年度存量調查**。若四象限框架要在巴西跑，SE 象限的 `ΔS = C − δS` 與檢定 2（隱含汰換率）在單一普查週期內基本無法評分，只能等下次普查（2032／2033）才有第二個資料點可以算變動率。

2. **完工量沒有官方登記／普查等級的來源，只有開發商協會的月度代理指標。** Abrainc-Fipe 是本次唯一測到可用的完工／推案／銷售資料，但涵蓋範圍是「Abrainc 會員開發商」，非普查或建照登記全體，涵蓋率未知。CBIC 與聖保羅市府建照資料兩條路都被防爬蟲機制擋死，連基本測試都做不到——不確定是暫時性技術障礙還是刻意封鎖，需要更多時間（例如換 IP／改用官方 API 申請流程）才能判斷是否有繞過的可能。

3. **S_shadow（已售未使用）本次完全未查。** 任務範圍的四類沒有明確涵蓋這一項，本次也未在信貸、存量、總經、制度四類的查找過程中撞見任何巴西版的空置代理指標。馬來西亞在方法論 §7.8 已把 S_shadow 結案為「不可量測成序列」，巴西大概率同樣困難甚至更難（普查頻率更低），但這是推測，不是本次驗證的結論。

4. **SBPE vs FGTS 的完整拆分仍不完整。** BCB SGS 找不到 FGTS 個人房貸專屬序列（🔴），只能用 Abecip 月報 PDF 拿到 SBPE 專屬放貸量，且 PDF 是非結構化格式，需要人工或另寫解析器逐期抄錄，不像 BCB SGS 那樣一行 API 呼叫拿到結構化歷史序列。

5. **地價序列完全缺失，Tobin's q 的 K 只解決了一半。** INCC／CUB-SP 解決了「營造成本」這一半（優於馬來西亞），但地價序列本次未找到來源（也未列入查詢範圍去找），K 的完整式子仍不可得。

6. **實質利率沒有官方現成序列。** 名目 Selic 與 IPCA 都已驗證，但事後實質利率（Selic − IPCA）沒有找到 BCB 或 IPEADATA 直接發布的序列，需自行用費雪方程式計算並在方法論中明寫「自算，非官方序列」。
