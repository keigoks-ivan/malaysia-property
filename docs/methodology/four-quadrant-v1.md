## 一、定位：這份文件是什麼、不是什麼

`property-forecast-v1.md` 是**程序**——六步怎麼做一份研究，經四場盲測驗證。
本文件是**結構**——市場的四個部門如何互相約束，用會計恆等式寫死。

兩者的關係是互補的：四象限提供 forecast v1「第 2 步供需平衡表」的理論骨架，並把原本散在四本帳裡的變數各自歸位（哪個變數影響哪一格、透過哪一條式子）。**衝突時以 forecast v1 的可信度分層為準**，本文件不推翻任何已驗證的分層。

### 為什麼需要這個結構

前一代的「五因子框架」（貨幣×需求×供給×制度×替代）是一份**清單**：項目之間沒有結構關係，所以每一條都得單獨對經驗資料，一條倒了整個就鬆掉。六個測試的實際結果是 T1 貨幣橫斷面不成立、T7 供給彈性無法評分、T6 信貸→價是唯一站得住的鏈環。

四象限的性質不同：**它是會計恆等式，不是相關性主張**。租金、價格、新建量、存量之間的關係是定義出來的，不是估計出來的。因此：

- 它**不會回測失敗**，因為它不預測。
- 它產出的是**一致性檢定**：這四個觀察值能不能同時成立？不能的話，是哪一格說謊、哪個變數必須調整？
- 輸出是方向與排序，不是點估——與已驗證的 Tier 1 強／Tier 3 弱分層天然相容。

**本文件不產生報酬預測。** 任何試圖從本框架導出「年化 X%」的用法都違反規格。

## 二、四象限恆等式與符號

```
                        租金 R
                          ↑
     NW ──────────────────│────────────────── NE
     資產定價              │              空間市場
     P = R / i            │          D(R, X) = S
     「值多少」            │           「租金誰決定」
     ←─── 價格 P ─────────┼───────── 存量 S ───→
     SW                   │                   SE
     開發決策              │              存量調整
     C = f(P, K)          │          ΔS = C − δS
     「蓋不蓋」            │           「存量怎麼走」
                          ↓
                       新建量 C
```

### 符號表

| 符號 | 定義 | 口徑要求 |
|:---|:---|:---|
| R | 年**淨**租金（扣管理費、稅、空置與收租損失後） | 每 sq ft 或每戶，須與 P 同口徑 |
| P | 資產價格 | 實際成交口徑優先，asking 永不當錨（承 forecast v1） |
| S | 可使用存量 | 見第三節的雙層拆解 |
| C | 每期新完工量 | 完工（completions），非開工、非推案 |
| δ | 汰換率（拆除＋永久退出使用） | MY 無官方序列，屬**假設參數**，須做敏感度 |
| i | 資本化率 | i = R / P（觀察值）；理論分解 i = r_f + ρ − g |
| K | 重置成本（土地＋營造＋合理利潤） | 見 §5 SW 象限取數 |
| X | 空間需求的外生變數 | 就業、所得、家戶形成 |

### 四條恆等式

1. **NE 空間市場出清**：`D(R, X) = S` — 租金調整到讓空間需求等於可用存量
2. **NW 資產定價**：`P = R / i` — 價格是租金流的資本化
3. **SW 開發供給**：`C = f(P, K)`，`f' > 0`，且 `P < K ⇒ C = 0`
4. **SE 存量調整**：`ΔS = C − δS`；穩態 `S* = C / δ`

**閉合條件**：穩態要求四式同時成立且 `ΔS = 0`。矩形閉合＝均衡。

### 讀圖鐵律

- **順時針有因果意義**：經濟成長 → 空間需求上升（NE）→ 租金漲 → 資產價格漲（NW）→ 開發商動工（SW）→ 存量增加（SE）→ 回壓租金（NE）。
- **逆時針沒有因果意義**。不得從存量倒推租金、從新建量倒推價格當作預測。這是本框架最常見的誤用。
- 矩形只描述**比較靜態**：它告訴你新均衡在哪一邊，不告訴你走多久、會不會超調。

## 三、亞洲修改：S_total 與 S_effective 的拆解

### 問題陳述

DW 原始模型的 NE 象限寫 `D(R, X) = S`：需求等於存量。這個等式隱含一個假設——**每一單位存量都會進入使用市場**。在美國商用不動產成立（空著的辦公室對業主純粹是損失，一定去找租客）。

**在吉隆坡、曼谷、杜拜不成立。** 大量單位蓋了、賣了、然後空著。買家買的不是空間，是資產。這些單位在 SE 象限計入存量，卻從未進入 NE 象限的租金決定過程。**矩形在這裡漏水。**

### 修改：存量拆兩層

```
S_total       法定完工存量（SE 象限的會計對象）
  − S_overhang     未售完工餘屋（開發商持有）
  − S_shadow       已售但未進入使用市場的投資持有空置
  = S_effective 有效供給（NE 象限的租金決定分母）
```

### 修改後的式子

- **NE 改寫**：`D(R, X) = S_effective`
- **SE 不變**：`ΔS_total = C − δ·S_total`
- **新增第五式（懸置供給釋放閥）**：
  `ΔS_effective = ΔS_total − ΔS_overhang − ΔS_shadow`
  其中 `ΔS_shadow = −Λ(h, g^e) · S_shadow`，Λ ＝ 釋放率，是持有成本 h 的增函數、預期漲幅 g^e 的減函數。

### 這解釋了什麼

**KL／曼谷／杜拜餘屋高企多年，租金卻沒有崩。** 原因不是需求強，是那些單位根本不在 NE 象限的分母裡。它們是**懸而未落的供給**。

一旦持有成本上升（房貸利率、空屋稅、租金所得稅制改變）或漲幅預期熄火，Λ 上升，懸置存量會倒進 S_effective——**那才是租金真正的下行風險點，而且它跟價格的關係是反直覺的**。

### 為什麼馬來西亞是最適合驗證這個修改的市場

NAPIC 是亞洲少數把 overhang 當官方統計逐季公佈的機構（residential FY2025 30,471 / 1Q2026 32,801；SA FY2025 18,752 / 1Q2026 19,263，全部來自官方 Status Tables）。`S_overhang` 這一層在 MY **可以直接量測**，不必推估。

`S_shadow`（已售空置）在 MY 沒有直接統計，須用代理估計——這是本框架在 MY 的**主要未解取數問題**，列於 §5。

## 四、矩形閉合檢定（操作核心）

給定一個市場觀察到的 (R, P, C, S)，模型隱含四個一致性條件。做法是**反推每一個隱含值，與獨立基準比對**。

| # | 隱含值 | 算式 | 對照基準 | 不符時的診斷 |
|:---|:---|:---|:---|:---|
| 1 | **隱含租金成長** g\* | `g* = r_f + ρ − R/P` | 歷史實質租金成長、名目所得成長 | g\* 遠高於所得成長 ⇒ NW 的價格靠預期撐、非租金撐；租金無法追上時價格必須讓 |
| 2 | **隱含汰換率** δ\* | `δ* = C / S_total` | 住宅實際汰換 0.5–1.5% | δ\* ≫ δ ⇒ 存量在膨脹；NE 要求 R 下跌，除非需求同速成長 |
| 3 | **隱含需求成長** | `(C − δ·S_total) / S_effective` | 家戶形成率 ＋ 所得彈性 × 所得成長 | 缺口 ⇒ 未來餘屋的機械預測（這是四項裡最可靠的一項） |
| 4 | **隱含 Tobin's q** | `P / K` | 1.0 | q>1 但 C 低 ⇒ SW 有制度阻塞（土地／法規）；q<1 但 C 高 ⇒ 非市場動機（土地融資、政治工程、預售制度） |

### 輸出格式（規格凍結）

四格各自標記，並**指名必須調整的變數**：

- `✓ 相容` — 隱含值落在基準的合理帶內
- `⚠ 張力` — 偏離但可用其他象限的觀察解釋
- `✗ 不相容` — 偏離且無法解釋 ⇒ 該象限的某個觀察值或某個參數必然錯

**禁止事項（承 forecast v1 Tier 3 規則）**：
- 禁止把檢定結果轉換成價格點估或年化報酬預測
- 禁止用單一時點的四格讀數宣稱轉折——本框架對時點失明（見 §7）
- ⚠ 與 ✗ 只說「哪個變數必須調整」，不說「何時調整」

### 為什麼這比五因子清單耐用

第 3 項（隱含需求成長）是純機械的：完工量減汰換量除以有效供給，得到「這些新單位需要多快的需求成長才吸收得掉」。這個數字不需要任何行為假設，也不需要估計任何彈性——它是**恆等式的直接後果**。T7 供給彈性估不出來不影響它。

## 六、可證偽條件與前瞻凍結

以下三條命題**於本文件凍結日寫死**，之後不得依資料調整判準。全部為排序／方向型（Tier 1 象限），無一為量級型。

### F1 — 懸置閥門命題（第三節的核心主張）

**命題**：在持有成本上升期間（有效房貸利率累計上行 ≥100bp 的窗口），KL 高層公寓的**租金指數轉折早於價格指數轉折 ≥1 季**。

**理由**：若 Λ 機制為真，持有成本上升會先把懸置存量推進 S_effective，NE 象限先受衝擊；NW 象限的價格要等資本化率與預期調整才動。

**推翻條件**：租金轉折**落後**價格，或兩者同步（差 <1 季）⇒ 懸置存量不是主要機制，第三節的修改應退回 DW 原版。

**可用的自然實驗**：2022Q2–2023Q2 OPR 1.75%→3.00%（+125bp）。**注意：此窗口為歷史樣本，用它檢定屬 in-sample，結果須明示為 in-sample 並不得作為前瞻宣稱。** 前瞻樣本＝下一次 ≥100bp 上行窗口。

### F2 — 存量膨脹排序命題

**命題**：以州為單位，`δ* = C / S_total` 連續 3 年 ≥3% 的州，其後 5 年的 MHPI 州別相對表現**落後**全國中位。

**檢定**：Spearman ρ（δ\* 排名 vs 後續 5 年相對報酬排名）≤ −0.3 為通過，−0.3～0 為弱，>0 為推翻。門檻於本日凍結。

**資料**：NAPIC by-state 完工／存量＋MHPI 州別分項。全部為歷史資料 ⇒ **首跑為 in-sample，須明示**。前瞻凍結見下。

### F3 — q 阻塞命題

**命題**：`q = P/K < 1` 的期間仍維持高完工量的市場／州，其餘屋累積速率高於 q > 1 的市場／州。

**推翻條件**：兩組餘屋累積速率無差異或方向相反 ⇒ SW 象限的 `P < K ⇒ C = 0` 條件在 MY 不適用（可能因預售制度使開發商的決策點不在完工時，而在推案時）。

### 前瞻凍結條目

本文件凍結時，於 `forward-ledger.md` 另立條目登記 F1（前瞻窗口）與 F2（前瞻 5 年），評分日與評分規則於該處寫死。**歷史資料上的首跑一律標記 in-sample，不得計入前瞻成績。**

## 七、已知邊界（照登，不修飾）

1. **轉折時點仍然失明。** 承接 forecast v1 反模式 #5——四場盲測兩次現形（台灣 2016 底部、新山 RTS V 型）。四象限是比較靜態框架，給的是**失衡方向與必須調整的變數**，不給時點與幅度。轉折偵測仍然外包給絆線。

2. **自住為主市場的 R 是設算的。** MY 自住率高，租賃市場只覆蓋部分存量。因此 NE 象限的檢定**只在租賃活躍的產品有效**（KL 高層公寓、SA），**有地住宅（landed）不適用**——landed 的 R 無法觀察，套用等於捏造。這是產品層的適用邊界，不是可以忽略的細節。

3. **g\* 是恆等式的殘差，不是獨立估計。** `g* = r_f + ρ − R/P` 裡的 ρ 是假設參數，所以 g\* 的誤差全部吸收 ρ 的誤差。它只能用來問「這個 g\* 合理嗎」，永遠不能當預測值引用。

4. **δ 與 ρ 都是假設參數。** 兩者在 MY 都沒有官方序列。任何結論都必須附敏感度區間；若結論在合理參數帶內會翻轉，該結論不成立。

5. **NE 的需求函數 D(·) 混了消費需求與投資需求。** 這是 DW 原版就有的弱點，第三節的 S_shadow 拆解只處理了供給側的漏水，需求側的投資成分（外籍買家、MM2H）仍然混在一起。屬 v1.1 未解問題。

6. **Bertaud 層尚未落地。** 容積制度、可建地存量、通勤可及性三項在 KL 全部 🔴。因此本版的 SW 象限只有價格—成本關係，**沒有制度彈性維度**——這正是 T7 判 NOT SCORABLE 的那一格，改道方案（用可觀測制度代理做三態序數判定，不估彈性）已設計但未執行。

7. **逆時針不可讀。** 重申，因為這是最容易犯的誤用。

8. **S_shadow 在馬來西亞無法量測成序列（2026-08-02 結案）。** 五個候選代理全數評估，四個證偽、一個未結：公用事業零用量（ST／TNB 只公佈按關稅類別的帳戶總數，無用量分級；帳戶數比 NAPIC 半島住宅存量多 51%，母體根本不同）／CCC vs 評估稅（評估稅按估值課徵、對占用狀態失明；第 162 條 elaun kekosongan 要求業主證明「已努力出租而未果」，篩出來的正好是 S_shadow 的**補集**）／租賃登記（MY 無強制登記制度，前提不成立）／OpenDOSM `hh_lq_state`（KL 2017–2019 算出負空置率、2019→2020 有 11.3pp 斷點，實測死亡）；SPAN 連線逾時，標為未結而非「已確認無資料」。最強旁證：推動空屋稅立法的 KRI 自己也只能用普查，並寫明資料無法分辨投機持有。

   **後果**：§3 的亞洲修改**降級為定性機制＋單點錨**，不是可量化的分層。唯一觀察值是 KL 2020 普查——空置 92,429 戶（14.6%），其中可對應 S_shadow 的「度假屋／過境屋」18,036 戶，真值區間 18,036～92,429（未分類殘差 25.3% 拆不開），寬到沒有判別力，且分母是普查母體不得除 NAPIC 存量。

   **對 §4 檢定 3 的操作處置**：分母退回 `S_total − S_overhang`，並**固定加註偏誤方向——分母偏大 ⇒ 隱含需求成長被系統性低估 ⇒ 退回版的檢定 3 偏樂觀**。這句話必須永遠跟著數字走。

   **翻盤觸發條件（登記三條）**：①ST／TNB 公佈住宅帳戶用量分布（半島 910 萬具智慧電表 2029 年前裝設完成，屆時資料必然存在）②2030 普查把「新完工／待租售」拆成「未售」與「已售待租」③MY 立法課空屋稅——課稅會創造行政空置登記，那將是第一個真正的 S_shadow 觀察值。

9. **現有租金指數無法判定 F1 的轉折時點（2026-08-02 發現）。** DOSM CPI 041 已取得且品質好，但性質不對：它量的是**續約中的租約存量**，197 次月變動只動 68 次、其中 66 次落在季度第二個月——**是季頻序列穿月頻的衣服**，有效觀察數 66 個季度點，剛好卡在 F1「≥1 季」的解析度下限、零冗餘。更要命的是它隨換約才逐批反映市場租金，**結構上天生落後於成交價指數**，而 F1 的對照腿是 MHPI。這個配對在結構上偏向推翻 F1，跑出的結果**無法分辨「Λ 機制不成立」與「儀器本來就慢」**。

   佐證：186 個年增觀察值**從未轉負**（最低 +0.394% @ 2021-02）；2022Q2–2023Q2 的 OPR +125bp 窗口裡租金反而**加速**（季環比 0.339%→0.639%），MHPI 同期也一路上行——**兩條腿都沒有轉折，F1 首跑無法執行**。條目 004 的絆線③「CPI 租金分項年增轉負」在 16 年紀錄裡從未觸發，近乎不可達。

   **§6 的 F1 規格維持凍結不動。** 這是儀器限制不是命題錯誤，處置照 `forward-ledger.md` 紀律走：不改條目 004，另開條目 006 記載並交叉引用。F1 要復活需要 KL 或高層分項的**成交**租金序列（見 §5 下一輪清單第 7 項）。

## 九、MY 首跑結果（2026-08-02）

**全部為 in-sample，不計入任何前瞻成績。** 規格章節未動；以下是套用結果與應用註記。

### 9.1 SE 恆等式在 MY 官方資料上不成立，且方向固定

`ΔS = C − δ·S` 要求 δ ≥ 0 ⇒ **ΔS 必須小於 C**。實際：ΔS 每年比 C 多出存量的 **0.6–1.3%**，非斷點季 **64/71 為正**。

四個假設逐一證偽（集中於某型別／某州／一次性重述／覆蓋最弱處最大），真正原因在 NAPIC 年度 `Laporan` 的 Technical Notes：調查「has not reached a total population count」，**存量是還在擴張的調查底冊**，會吸收「本來就存在、這季才納入調查」的舊單位；完工只計既有範圍內當季發 CF/TCF 者。**兩欄涵蓋範圍本就不同，是定義問題不是資料錯誤。** NAPIC 不公布調整項分解，累計 436,237 戶無法拆成各管道佔比，照實記為量級不明。

**檢定 2 的應用註記（規格未改）**：δ\* 不報點估。`C/S` 是**下界**（漏掉範圍外完工）、`ΔS/S` 是**上界**（含非新建的帳務增量），偏誤方向已知相反、幅度不可觀測。

| 用途 | 敏感度 |
|:---|:---|
| **水準型**（對 0.5–1.5% 汰換帶） | **高度敏感、結論會反轉**。2025 全國 `C/S` = 1.53% 貼著帶子上緣，`ΔS/S` = 2.82% 遠遠超出 ⇒ 必須報區間 |
| **排序型**（F2／條目 005） | 大致一致但**不可互換**。16 州兩口徑 Spearman 2018–2025 平均 0.710，但 2020 年低到 0.550，**低於 ledger 對排序型預測的 ρ≥0.6 及格線** ⇒ 評分時兩口徑都算，若在 −0.3 門檻兩側分歧記為無法判定 |

### 9.2 檢定 1：實質租金成長是零

| 序列 | 2010 年均 | 2025 年均 | 年化 |
|:---|---:|---:|---:|
| CPI 041 住宅租金 | 100.008 | 136.342 | +2.088% |
| CPI headline | 100.017 | 134.625 | +2.001% |
| **實質租金** | | | **+0.085%** |

四捨五入是零。同期 MHPI（2010=100）2015 年 164.5 → 2025 年 233.1，名目年化約 +3.5%、實質約 +1.5%。

**讀法**：`P = R/i` 之下，R 實質不動而 P 實質年年上行 ⇒ **這十年的實質房價漲幅不是租金撐的，是 i 壓縮撐的。** 這正是檢定 1 設計來抓的東西。**但不得就此推論價格會回跌**——i 壓縮可以由利率、風險溢酬或預期成長任一項驅動，恆等式分不出是哪一項，而 ρ 是假設參數（§7.4）。這條結論的地位是「指出 NW 象限的張力所在」，不是預測。

### 9.3 F2 閘門的樣本量問題（提前發現，不改門檻）

以 F2 凍結的「δ\* 連續 3 年 ≥3%」掃 2008–2025，兩個口徑**都只篩出 2 州**（Putrajaya、Terengganu）。n=2 遠不足以做條目 005 指定的 Spearman 檢定。

**這是凍結命題的設計限制，不是資料問題。門檻不得為湊樣本而改**——評分日照實記為「樣本不足、無法評分」。提前寫在這裡，是為了讓 2031 評分時不會有人臨時想放寬門檻。

### 9.4 本輪的方法論教訓

三個交付物裡出現兩次同類錯誤，都出在**統計量自己算、定義不寫下來**：先是「殘差中位數 0.15%」用了中位**絕對**值把正負號藏掉，把單向系統性偏誤描述成對稱雜訊；再是自寫 Spearman 分母多除一個 2，把 ρ 從 0.710 推到 0.855。後者連帶讓兩個結論失真——「F2 免疫於口徑之爭」（已撤回）與高層佔比檢定的「證偽」（正確值 ρ=−0.415、p=0.110，符號相反，方向其實**符合**假設但 n=16 不顯著，已改判 INDETERMINATE）。

**規則**：凡進入本框架的統計量，`method` 必須與數字同檔存放（統計量定義、變數算式、分母、n、tie 處理、年份對齊），使任何人能獨立重算。只給結論不給口徑的數字，視同未驗證。
